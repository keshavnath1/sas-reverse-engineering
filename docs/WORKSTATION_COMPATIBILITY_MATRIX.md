## Proposed workstation checks

**WS-1 is a read-only Bash launcher** for exactly one of `--help`, `--version` and `status` using an already approved, installed native CPython 3.12 package. The permitted report is stdout. Source, scope, config, store and report-file paths are outside this step. Setup, CP2 configuration validation, authorized synthetic runs and derived report views each need later approval. Formatting supplied public bytes for stdout could be pure on either qualified tuple; selecting a sealed store subject would require permitted filesystem access. No launcher mode may promote package authority or implement a weaker I/O fallback.
