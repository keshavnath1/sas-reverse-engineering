# sas-specify

1. Read the selected source and dependency evidence. Describe the business
   objective and consumers as supplied, and flag unknown intent for the owner.
2. Draft requirements with source anchors and observable acceptance criteria.
   Specify module inputs, outputs, schema and order obligations, transformations,
   branch conditions, error boundaries and unsupported scope where evidenced.
3. Separate declared behavior from proposed requirements and profile assumptions.
   Identify the owner decisions needed for ambiguity, ordering, missing values
   and tolerances. Return a draft PRD and functional or module specifications.

Follow the [repository rules](../../AGENTS.md). Use the selected authorized
package and cite its evidence. Keep drafts DRAFT, verification UNVERIFIABLE,
acceptance BLOCKED, and unperformed execution NOT_RUN.
